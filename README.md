# Software Applications for Computer Science – WiSe 26/27

Welcome! 👋 This repository contains all slides, tutorials, and handouts for the seminar **"Software Applications for Computer Science"** at HS Fresenius (winter semester 26/27).

---

## 🛠️ Before the Next Class: Setup Checklist

From now on, **we will do something hands-on in every session, so ALWAYS bring your laptop!**

Please make sure you have:

- [ ] A **GitHub account**
- [ ] A **Claude account**
- [ ] **A Mac**, or **a Windows PC with Ubuntu (WSL) installed**

**Using Windows?** Please install WSL with Ubuntu *before* class if you have not already done it. Don't worry if you have never used a terminal before. Just ask Claude:

> *"I am a freshman who is just learning how to use the terminal. Please explain in an easy way how to install WSL on my Windows PC."*

## 🎤 Your Presentation

After the midterms, it's your turn! Giving a presentation is **required to pass this seminar**.

**1. Find your topic and date**
- 📅 [Presentation schedule](https://github.com/markoduda/Software-Applications-for-Computer-Science-WiSe-26-27/blob/main/presentation_schedule.md)
- 📄 [Topic details and general guidelines](https://github.com/markoduda/Software-Applications-for-Computer-Science-WiSe-26-27/blob/main/topics_for_your_presentation.pdf)

**2. Hand in your handout (mandatory!)**

⚠️ Without a handout, you won't pass the course.

- 📤 [Upload it here (ILIAS)](https://ilias.hs-fresenius.de/ilias.php?baseClass=ilexercisehandlergui&cmdNode=d2:nx&cmdClass=ilObjExerciseGUI&cmd=showOverview&ref_id=3570049)
- ⏰ Submit it **before the day of your presentation**, so I can publish it on GitHub for everyone.
- Please provide **two formats**:
  - GitHub Flavored Markdown (`.md`)
  - PDF version of your markdown

**Tips**
- **Want to include images?** Upload a **ZIP file** containing your Markdown file and an `images` folder.
- **How to convert markdown to a PDF?** Many free websites convert Markdown to PDF. Just search for *"Markdown to PDF"*.
